# Sarwar Uddin

Computer science student at North South University in Dhaka. I build small,
local-first apps in TypeScript, the kind I want to use myself, and release
them once they have tests, docs and an install that works.

## Released

* **[Sonic Archive](https://github.com/sarwar-uddin/sonic-archive)** — A catalog for a lossless CD collection that never writes to your music: CD images split by their CUE sheets, EAC and XLD rip logs checked against AccurateRip, booklet scans and OBI strips, pressings compared side by side, and dynamic range measured. TypeScript, React, Express and SQLite. [v0.1.0](https://github.com/sarwar-uddin/sonic-archive/releases/tag/v0.1.0)
* **[Static FM](https://github.com/sarwar-uddin/static-fm)** — A web radio for music saved on YouTube, with an early-2000s feel: stations on a tuner dial, a tape band that keeps copies with yt-dlp, and a record crate for the whole library. TypeScript, React, Express and SQLite. [v0.1.0](https://github.com/sarwar-uddin/static-fm/releases/tag/v0.1.0)
